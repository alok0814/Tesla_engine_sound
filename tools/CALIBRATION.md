# キャリブレーション

参照クリップのスペクトルに、正弦パーシャルと帯域制限ノイズだけを合わせた。録音は測っていない。音声ファイルはシンセに入れてない。

測定は `tools/render.mjs`（OfflineAudioContext）と `tools/measure.py`（STFT 8192、Hann）。走行は 3200 rpm、マスタング走行は 3000 rpm。アイドルは 1000 rpm。最初の 0.35 秒は捨てた。許容は k=1…6 が ±4 dB、重心が ±20%、アイドル→中回転の音量差が ±2 dB、120 Hz 未満のエネルギーが参照帯（−24…−34 dB）の ±5 dB、ヘルキャットのホイッスルが 0.712 Hz/rpm の ±3%。

| | 変更前 | 変更後 |

## 許容に入らなかったもの

- Hellcat の 1.5 次が +4.8 dB。正弦はプロファイルどおり弱い。±3% の探索窓にヘイズが入り、床が峰を 5 dB 持ち上げる。ヘイズを下げると重心（まだ −15%）がさらに下がる。
- Mustang の 5 次・6 次が +5.3 dB。同じ理由で、目標が −25 dB の弱い次数だけ窓内のノイズに負ける。1〜4 次と重心は許容内。
- アイドルの 120 Hz 未満。V8 で −19 dB、V12 と水平対向6で −6 dB。目標は −24…−34 dB。1000 rpm では点火基本波が 50 Hz（水平対向6）〜100 Hz（V12）にあり、最強のパーシャル自体がその帯域に入る。積分を −24 dB まで下げると、その次数がヘイズに埋まる。走行域は −31…−33 dB で、Ferrari だけ −40 dB と下限より約 6 dB 少ない。
- GT3 アイドルの重心が −26%。次数は ±1.6 dB。低回転のヘイズがまだ下に寄っている。
- GT3 のアイドル→中回転が +11.7 dB で、参照 +9.4 dB より 2.3 dB 大きい。Hellcat は +2.0 dB で境界。音量カーブは車ごとにフィルタの効きが違い、一つの係数では全車が ±2 dB に収まらない。
- ウラカンと GT-R に参照クリップはない。ウラカンは Ferrari と GT3 の中間、GT-R は GT3 を 4 次以上で約 8 dB 暗くした。GT3 との比較で高次がずれるのはその設定。
- 等速アップシフトの回転落ちは、参照の rpm/km/h 表そのもの。1→2 速は 0.63〜0.70 倍、3 速以降は 0.78〜0.84 倍。映像の 0.79〜0.82 倍は上のギアに近い。`shift()` は約 22 dB・90 ms のゲインディップだけで、回転の二度落としはしない。
- `measure.py` のホイッスル検出は、スーパーチャージャーのない車でも 0.71 Hz/rpm 付近の普通の峰を報告する。周波数の判定は Hellcat の負荷ありレンダリングだけを使う。
